# Labels del proyecto

## Tipo

- `feature`: nueva capacidad
- `bug`: correccion
- `design`: documento de diseno pre-implementacion
- `docs`: documentacion
- `refactor`: mejora interna sin cambio de comportamiento

## Estado

- `todo`: listo para arrancar
- `in-progress`: alguien trabajando
- `review`: necesita review
- `blocked`: bloqueado por otro issue
- `done`: mergeado a main

## Prioridad

- `p0-critical`: bloquea release
- `p1-high`: importante, no critico
- `p2-medium`: nice to have
- `p3-low`: exploratorio

## Area

- `core`: loop, estado, runtime
- `adapter`: capabilities, HTTP, browser, CLI
- `risk`: gate, scoring, policies
- `routing`: input/output entre steps
- `parallel`: ejecucion concurrente
- `simulation`: dry runs, mocks controlados
- `dsl`: lenguaje declarativo
- `meta`: meta-agente generativo
- `observability`: metricas, logs, health
- `infra`: CI/CD, tooling, repo

## MVP

- `mvp-v0.9`: congelado, solo bugfixes
- `post-mvp`: trabajo futuro
