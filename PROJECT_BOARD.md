# GitHub Projects - Kanban

## Columnas

1. Backlog: todo sin asignar.
2. Design: documentacion de diseno.
3. Ready: diseno aprobado, listo para codear.
4. In Progress: alguien trabajando.
5. Review: PR abierto, necesita review.
6. Done: mergeado a main o feature branch.

## Automations sugeridas

- Issue con label `design` -> Design.
- Issue asignado con label `todo` -> Ready.
- PR vinculado -> Review.
- PR mergeado -> Done y cerrar issue.

## Vistas

- MVP v0.9: solo bugs y refactors.
- v0.10 Parallel: issues #1, #2, #3.
- Roadmap: todos los milestones.
