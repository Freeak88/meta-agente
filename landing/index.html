Meta-Agente

Un sistema que crea agentes de software que trabajan solo.

Le decís qué querés que haga en lenguaje natural. El sistema arma un agente, lo simula, y lo pone detrás de una API REST lista para integrar.

Demo en 30 segundos

$ git clone https://github.com/Freeak88/meta-agente.git
$ cd meta-agente/mvp
$ cargo run -- --server

# En otra terminal
$ curl -X POST http://localhost:3000/agents \
  -H "Content-Type: application/json" \
  -d '{"intent": {"goal": "automatizar facturación AFIP", "domain": "finanzas"}}'

Qué hace v1.0

Interpreta
Convierte una intención humana en estructura operativa.
Genera
Produce OPL, un lenguaje declarativo para agentes.
Simula
Valida el agente antes de entregarlo.
Expone
Entrega el resultado por API HTTP.
